# pasiura.com

Personal portfolio of Andrii Pasiura, a frontend / fullstack developer from Kyiv.

Live at [pasiura.com](https://pasiura.com).

## What's inside

- **About**: who I am and what I'm looking for, with a downloadable CV
- **Experience**: the places I've worked and what I did there
- **Skills**: the tools and technologies I use day to day
- **Projects**: pet projects with screenshots, stack and links
- **Contact**: email with one-click copy, socials and my local Kyiv time

## Features

- Light and dark themes that follow your system setting, with a manual toggle
- Responsive layout designed separately for desktop and mobile
- Sticky header that highlights the section you're reading
- Accessible navigation, keyboard friendly and screen reader aware
- Fast and lightweight: a fully static page with very little JavaScript
- SEO ready, with structured data and social preview images

## Built with

Next.js, React, TypeScript and SCSS, with Iconify and Lucide icons.
